Recode factor variables from SAS to data.table

Author

Francesco Laganà

Published

November 6, 2026

Load packages:

library(data.table)

Exemple data:

DT <- data.table(
  id = c(1, 1, 1, 2, 2, 3),
  var = c(10, 20, 15, 5, 8, 12)
)

DT[, max_var := max(var), by = id]

1 SAS DATA STEP: SELECT GROUP

data DT;
    set DT;

    select;
        when (var = 10) gruppo = "A";
        when (var = 20) gruppo = "B";
        when (var = 15) gruppo = "C";
        otherwise gruppo = "ALTRO";
    end;
run;

1.1 data.table equivalent with fcase()

DT[, gruppo := fcase(
  var == 10, "A",
  var == 20, "B",
  var == 15, "C",
  default = "OTHER"
)]

DT

fcase() evaluates the conditions in sequence and returns the value associated with the first condition that evaluates to true.

1.2 Recode two or more variables

SAS code

select;
    when (var < 10) classe = 1;
    when (var >= 10 and var < 20) classe = 2;
    when (var >= 20) classe = 3;
    otherwise classe = 0;
end;

data.table code

DT[, classe := fcase(
  var < 10, 1L,
  var >= 10 & var < 20, 2L,
  var >= 20, 3L,
  default = 0L
)]

DT

2 SAS DATA STEP: if-then-else

To create dummies use this function (fifelse):

DT[, classe := fifelse(var > 10, "A", "B")]

DT

fifelse() is the equivalent of an IF-THEN-ELSE, whilst fcase() is particularly well suited to replicating SELECT-WHEN-OTHERWISE.

For the migration from SAS to R/data.table, use fcase() to translate the SELECT-WHEN blocks.

3 SAS IF-THEN DO; … END; ELSE DO; … END;

To translate a SAS block such as IF-THEN DO; … END; ELSE DO; … END; into a data.table, it depends on what you need to do: assign variables or execute multiple statements.

3.1 SAS: IF-THEN-ELSE with more assignments:

data want;
    set have;
    if var > 10 then do;
        classe = "A";
        flag = 1;
        valore = var * 2;
    end;
    else do;
        classe = "B";
        flag = 0;
        valore = var;
    end;
run;

data.table: multiple assignments using := This is probably the most natural way to write code when working with data.table.

DT[var > 10, `:=`(
  classe = "A",
  flag = 1L,
  valore = var * 2
)]

DT[var <= 10, `:=`(
  classe = "B",
  flag = 0L,
  valore = var
)]

DT
