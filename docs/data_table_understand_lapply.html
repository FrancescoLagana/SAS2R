Understanding apply() in R and data.table

Applying functions to multiple variables

1 What does lapply() do?

lapply() is a base R function that applies a function to each element of a list (or vector) and returns the results as a list.

It is particularly useful when you want to perform the same operation on multiple variables without writing repetitive code.

1.1 A basic example

Suppose we have a list containing three numeric vectors:

x <- list(
  a = c(10, 20, 30),
  b = c(5, 15, 25),
  c = c(2, 4, 6)
)

We want to calculate the sum of each vector:

lapply(x, sum)
$a
[1] 60

$b
[1] 45

$c
[1] 12

The result is:

$a
[1] 60

$b
[1] 45

$c
[1] 12

lapply() performs the following operations:

  1. Takes the first element (a).
  2. Applies sum() to it.
  3. Takes the second element (b).
  4. Applies sum() to it.
  5. Continues until all elements have been processed.
  6. Returns a list containing the results.

The general syntax is:

lapply(X, FUN, ...)

Where:

  • X is the list or vector to process.
  • FUN is the function to apply.
  • ... represents additional arguments passed to the function.

2 Using lapply() with data.table

One of the most useful applications of lapply() is processing several columns of a data.table simultaneously.

Consider the following frequency table:

library(data.table)

tab <- data.table(
  sex = c("Femmes", "Hommes"),
  Obligatoire = c(100, 150),
  Secondaire_II = c(200, 250),
  Tertiaire = c(300, 400)
)

tab
      sex Obligatoire Secondaire_II Tertiaire
   <char>       <num>         <num>     <num>
1: Femmes         100           200       300
2: Hommes         150           250       400

We want to calculate column percentages, so that each column sums to 100%.

2.1 Identify the columns to process

cols <- setdiff(names(tab), "sex")

cols
[1] "Obligatoire"   "Secondaire_II" "Tertiaire"

setdiff() returns all column names except "sex".

The result is:

[1] "Obligatoire" "Secondaire_II" "Tertiaire"

We exclude sex because it identifies the rows and does not contain numerical frequencies.

2.2 2.2 Understand .SD and .SDcols

In data.table, .SD stands for Subset of Data.

It represents the selected columns available for processing within the current group.

.SDcols specifies which columns should be included in .SD.

For example:

tab[, lapply(.SD, sum), .SDcols = cols]
   Obligatoire Secondaire_II Tertiaire
         <num>         <num>     <num>
1:         250           450       700

This calculates the sum of each selected column.

2.3 Calculate column percentages

tab[
  ,
  (cols) := lapply(.SD, function(x) {
    x / sum(x) * 100
  }),
  .SDcols = cols
]

tab
      sex Obligatoire Secondaire_II Tertiaire
   <char>       <num>         <num>     <num>
1: Femmes          40      44.44444  42.85714
2: Hommes          60      55.55556  57.14286

The result is:

sex Obligatoire Secondaire_II Tertiaire
Femmes 40.0 44.4 42.9
Hommes 60.0 55.6 57.1

Each column now sums to 100%.

2.3.1 How does this work?

Consider the expression:

lapply(.SD, function(x) {
  x / sum(x) * 100
})

lapply() processes each column separately.

For the Obligatoire column:

x <- c(100, 150)

x / sum(x) * 100

The calculation is:

  • Femmes: 100 / 250 × 100 = 40%.
  • Hommes: 150 / 250 × 100 = 60%.

The same calculation is repeated for the other columns.

Finally:

(cols) :=

assigns the resulting vectors back to their corresponding columns.

Important: := modifies the original data.table by reference. The frequency counts are therefore replaced by percentages.

3 lapply() versus sapply() versus vapply()

R provides three related functions for applying operations to multiple elements.

Function Return type Main purpose
lapply() List Apply a function to each element
sapply() Simplified object Apply and simplify the results when possible
vapply() Predetermined type Apply with an explicitly specified output type

Example:

lapply(x, sum)
$a
[1] 60

$b
[1] 45

$c
[1] 12
sapply(x, sum)
 a  b  c 
60 45 12 
vapply(x, sum, numeric(1))
 a  b  c 
60 45 12

All three calculate the sums, but their output structures differ.

vapply() is particularly useful when you want to enforce a predictable output type.

4 Other practical applications

The same principle can be used for many operations on multiple columns.

4.1 Calculate column means

tab2 <- data.table(
  age = c(20, 30, 40),
  income = c(3000, 4000, 5000),
  expenditure = c(1500, 2000, 2500)
)

tab2[, lapply(.SD, mean)]
     age income expenditure
   <num>  <num>       <num>
1:    30   4000        2000

4.2 Convert several columns to character

tab2[, (names(tab2)) := lapply(.SD, as.character)]

4.3 Apply rounding to several columns

tab2[, (names(tab2)) := lapply(.SD, as.numeric)]
tab2[, (names(tab2)) := lapply(.SD, round, digits = 1)][]
     age income expenditure
   <num>  <num>       <num>
1:    20   3000        1500
2:    30   4000        2000
3:    40   5000        2500

5 Why is lapply() useful in data.table?

Without lapply(), you would have to write separate expressions for every column:

tab[, Obligatoire := Obligatoire / sum(Obligatoire) * 100]

tab[, Secondaire_II :=
      Secondaire_II / sum(Secondaire_II) * 100]

tab[, Tertiaire := Tertiaire / sum(Tertiaire) * 100]

Using lapply() allows you to express the same operation once:

tab[
  ,
  (cols) := lapply(.SD, \(x) x / sum(x) * 100),
  .SDcols = cols
]

This approach is shorter, easier to maintain and particularly useful when the number of variables is not known in advance.

Key takeaway: lapply() is a fundamental tool for writing generic and reusable data.table code. It allows you to apply the same operation systematically to multiple columns without explicitly naming each variable.

6 sapply — simplify the result

# Applicare sqrt a ogni elemento di una lista
x <- list(a = 1:4, b = 9:12, c = 25)

x

[1]  9 10 11 12

4 4 1 
# Other exemple with a function
sapply(1:5, function(i) i^2)
[1]  1  4  9 16 25

Direct comparaison

lapply(1:3, function(i) i * 2)   # → lista: [[1]] 2  [[2]] 4  [[3]] 6
[[1]]
[1] 2

[[2]]
[1] 4

[[3]]
[1] 6

⚠️ Common pitfall: If the function sometimes returns NULL, supply may return a list instead of a vector—it’s better to use vapply in production scripts.

7 apply — on matrices/arrays, by row or column

m <- matrix(1:9, nrow = 3, byrow = TRUE)
m
     [,1] [,2] [,3]

8 mapply — function with multiple arguments in parallel

# Ripetere una stringa n volte, con n variabile
mapply(rep, x = c("a", "b", "c"), times = c(1, 2, 3))
$a
[1] "a"

$b
[1] "b" "b"

$c
[1] "c" "c" "c"
# Esempio numerico: somma elemento per elemento
mapply(function(a, b) a + b, 1:3, 10:12)
[1] 11 13 15

9 tapply — apply by groups

# Media degli stipendi per reparto
dati <- data.frame(
  stipendio = c(2000, 2500, 3000, 1800, 2200, 4000),
  reparto   = c("A", "A", "A", "B", "B", "C")
)

tapply(dati$stipendio, dati$reparto, mean)
   A    B    C 
2500 2000 4000 
#>       A        B        C
#> 2500.00  2000.00  4000.00

tapply(dati$stipendio, dati$reparto, length)
A B C 
3 2 1 
#> A B C
#> 3 2 1

10 vapply — like sapply, but with a declared type

# Dichiaro che ogni risultato è un numeric di lunghezza 1


# Se la funzione restituisce un tipo diverso → errore esplicito
vapply(list(1:3, 4:6), length, numeric(1))  # OK → 3 3
[1] 3 3
# vapply(list(1:3, 4:6), length, character(1)) ❌ Errore: tipo sbagliato

Advantage: If something goes wrong, you get a clear error instead of a silently incorrect result, as with sapply.

11 Built-in Example: Data Cleaning

Scenario: You have a list of data frames and want to extract the number of rows and columns.

df_list <- list(
  df1 = data.frame(a = 1:3, b = 4:6),
  df2 = data.frame(x = 1:5),
  df3 = data.frame(y = 1:2, z = 3:4, w = 5:6)
)

# Dimensions of each data frame
sapply(df_list, dim)
     df1 df2 df3
[1,]   3   5   2
[2,]   2   1   3
# Number of rows as a simple vector
sapply(df_list, nrow)
df1 df2 df3 
  3   5   2
